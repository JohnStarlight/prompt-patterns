# Data Extraction Template

## Input 1:
John Doe, age 29, lives in Paris and works as a software engineer.

### Result:
{"Name": "John Doe", "Age": 29, "Location": "Paris", "Occupation": "Software Engineer"}

## Input 2:
Last week, I met Sarah Jenkins. She's 42, based in Tokyo, and is currently a senior architect.

### Result:
{"Name": "Sarah Jenkins", "Age": 42, "Location": "Tokyo", "Occupation": "Senior Architect"}

## Input 3:
Marketing Lead: Marcus Thorne (35). Current city: Berlin.

{"Name": "Marcus Thorne", "Age": 35, "Location": "Berlin", "Occupation": "Marketing Lead"}
